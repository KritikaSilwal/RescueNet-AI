# 🚨 RescueNet AI

## AI-Powered Disaster Response & Recovery Prediction System

RescueNet AI is a Machine Learning-powered disaster management platform that predicts disaster recovery time and assists emergency response teams with data-driven decision-making.

---

## 🚀 Features

- 🤖 Predict Disaster Recovery Time
- 🌍 Disaster Location Visualization
- 📊 Interactive Analytics Dashboard
- 🚨 AI-Based Emergency Decision Support
- 📈 Machine Learning Prediction Model
